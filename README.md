# Tool Edit

Video editor for Windows 64-bit.

[Download installer](https://github.com/MKPPF/tool-edit-releases/releases/latest/download/ToolEdit-Setup.exe)

Install, open Tool Edit, and send your machine code to the seller for a license key. Python is included. If prompted, install the video engine inside the app.

The app checks for signed updates on startup and every 30 minutes, and applies downloaded updates when exiting.

This repository distributes installers and update metadata. Source development is maintained privately.
